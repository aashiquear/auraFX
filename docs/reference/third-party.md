# Third-party code in the CAD environment

The B-rep kernel and the CAD file formats are carried in this repository under `vendor/`
(`vendor/README.md` says how, and how upstream work is taken). This table is generated by
`scripts/cad/third-party.sh` from `cargo metadata` of `aurafx-cad`: every crate its build
uses that is not auraFX's own, grouped by where it comes from and its SPDX licence.

auraFX credits SolidCraft (https://github.com/tangency-labs/solidcraft, MIT OR Apache-2.0)
and solidcore (https://github.com/tangency-labs/solidcore, Apache-2.0) as libraries; the
parametric part model, sketch solver and expression evaluator were ported from the
author's own EZ-YX-craft project (MIT OR Apache-2.0).
